# ۲۴۰۰ داستان

نسخه بهینه‌شده سایت استاتیک فارسی با بارگذاری تنبل داستان‌ها.

## بهینه‌سازی داده‌ها
- `data.js` فقط فهرست دسته‌بندی‌ها و عنوان/شناسه داستان‌ها را نگه می‌دارد.
- متن کامل هر دسته در فایل مستقل `s1.js` تا `s10.js` قرار دارد.
- با ورود به یک دسته فقط فایل همان دسته بارگذاری می‌شود.
- با باز کردن یک داستان از جستجو، فقط فایل دسته مربوط به همان داستان بارگذاری می‌شود.

## دسته‌بندی داستان‌ها
داستان‌های دسته‌ها مطابق درخواست جابه‌جا شده‌اند و «حکایت ها» آخرین دسته است.
